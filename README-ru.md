# Audio Transcript

[English](README.md) · [Русский](README-ru.md) · [Español](README-es.md) · [Deutsch](README-de.md)

Audio Transcript — небольшое приложение для Windows 11, которое превращает голосовые сообщения Telegram, аудиофайлы и звук из локальных видео в точные текстовые расшифровки. Есть последовательная очередь, просмотр результата, копирование в буфер обмена и сохранение TXT и Markdown.

Распознавание выполняется локально с помощью `faster-whisper` и CTranslate2. После установки зависимостей и моделей локальные файлы можно обрабатывать без интернета. Исходные записи и расшифровки остаются на компьютере; приложение не использует API распознавания, учётные записи, телеметрию, облачное хранилище, сервер или базу данных.

## Требования

- Windows 11; 64-разрядный Python 3.11 или 3.12.
- Интернет для первоначальной установки и скачивания звука с YouTube.
- Для YouTube: Node.js 22+ или Deno 2.3+ в PATH.
- Достаточно свободного места для обеих моделей Whisper.

Обработка рассчитана на CPU и использует CTranslate2 `int8`; дискретная видеокарта не требуется.

## Первоначальная установка

В PowerShell из корня репозитория:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\bootstrap_models.bat
```

Скрипт скачивает обе модели CTranslate2 в папки проекта:

- `models\whisper-large-v3` — **Точность — Whisper large-v3**.
- `models\whisper-large-v3-turbo` — **Скорость — Whisper large-v3-turbo**.

Повторный запуск пропускает полностью установленные модели. Файлы моделей игнорируются Git. При обычном запуске модели не скачиваются; отсутствие модели вызывает понятную ошибку с инструкцией.

## Запуск и язык интерфейса

Дважды нажмите `run.bat`. Приложение запускается через `.venv\Scripts\pythonw.exe`; терминал для повседневной работы не нужен.

Над панелью настроек выберите **Язык интерфейса**: English, Русский, Español или Deutsch. Переключатель доступен при скрытых настройках и во время обработки. Изменение применяется сразу и сохраняется в `config/settings.json`. При первом запуске используется поддерживаемый язык интерфейса Windows; если он не поддерживается, выбирается английский.

Это настройка только интерфейса. Язык речи определяется автоматически; текст расшифровки, имена файлов и метаданные Markdown не переводятся. Технические сведения об ошибках сохраняют исходные формулировки.

## Порядок работы

1. При необходимости раскройте **Настройки**. Выберите **Точность** для максимальной верности текста или **Скорость** для более быстрой обработки на CPU.
2. При желании задайте имя говорящего по умолчанию. Его можно менять отдельно в каждой строке очереди.
3. Выберите **Папка проекта / transcripts** или **Рядом с исходным файлом**.
4. Перетащите файлы в окно, нажмите **+ Файлы**, **+ Папка** или **Входящие** для сканирования `inbox\`. Вложенные папки не обходятся. Для YouTube вставьте ссылку и нажмите **Добавить ссылку** или Enter.
5. Упорядочьте строки кнопками **Выше / Ниже**; можно выбрать несколько строк. Нажатие заголовка сортирует по возрастанию, повторное — по убыванию. **Добавлено** показывает местные дату и время добавления в текущую очередь, а не изменения файла.
6. Нажмите **Расшифровать**. Записи обрабатываются последовательно в порядке строк; окно остаётся отзывчивым. Во время обработки перестановка недоступна.
7. Выберите готовую строку для просмотра; нажмите **Копировать** для чистого текста или **Открыть папку** для результатов.

**Остановить** запрашивает безопасную отмену текущей очереди. Готовые результаты сохраняются, следующие файлы не запускаются, оставшиеся записи можно обработать позже. **Повторить выбранные** обрабатывает только выбранные записи с ошибкой или отменённые, в порядке очереди. **Убрать готовые** удаляет готовые строки. Удаление строк и очистка очереди не удаляют исходные файлы и расшифровки.

**Скрыть настройки** освобождает место для очереди и просмотра. Выбранные модель и место сохранения видны в кнопке раскрытия; полная подпись доступна во всплывающей подсказке. Состояние панели сохраняется локально. Сортировка применяется однократно: новые файлы добавляются в конец, ручное перемещение отменяет прежнюю сортировку. Неизвестная длительность при сортировке по возрастанию идёт первой. Очередь и время добавления не восстанавливаются после перезапуска.

## Видео YouTube

**Добавить ссылку** проверяет адрес и добавляет видео без обращения к YouTube. **Расшифровать** скачивает звук и передаёт его выбранной локальной модели Whisper. Видео и локальные файлы используют общую последовательную очередь. Прогресс скачивания и распознавания отображается отдельно. Остановка срабатывает на ближайшей безопасной границе; выполняющийся сетевой запрос может ждать своего тайм-аута.

При проверке на бота строка показывает **Ожидание повтора** в течение 10 секунд. Затем выполняется одна повторная попытка с новой гостевой сессией скачивания. Остановка отменяет и ожидание. После повторного отказа можно позже нажать **Повторить выбранные**; остальные записи продолжают обрабатываться. Для других категорий ошибок дополнительная попытка не выполняется, но сохраняются ограниченные повторы соединений и фрагментов в загрузчике.

Просмотр ошибки различает проверку на бота, ограничения доступа, недоступность видео, ошибки сети/сервера, отклонение медиа-запросов, отсутствие компонентов и форматов аудио. Технические сведения включают этап, число попыток, версии компонентов и до пяти фиксированных предупреждений. Не сохраняются исходные логи загрузчика, cookies, заголовки запросов и адреса медиа; диагностический файл на диск не записывается.

Поддерживаются `youtube.com/watch?v=...`, `youtu.be/...`, Shorts и ссылки на встроенные видео. Параметры отслеживания, временные метки и плейлисты удаляются: обрабатывается одно видео целиком. Ссылки только на плейлист/канал, текущие и предстоящие трансляции не поддерживаются. Видео должно быть доступно без входа; приложение не импортирует cookies браузера и не использует аккаунты.

`yt-dlp` скачивает звук во временную папку `config/youtube-*`. Она удаляется после успеха, ошибки или отмены. Принудительное завершение процесса или отключение питания может оставить временную папку. Постоянный архив видео/аудио не создаётся; локальные исходники не удаляются.

Результаты YouTube всегда сохраняются в `transcripts/YYYY/YYYY-MM-DD/youtube-VIDEO_ID/`, даже если для локальных файлов выбрано сохранение рядом с исходником. При совпадении имени добавляется номер. Markdown содержит адрес и название видео; TXT — только текст локальной модели. Название появляется в готовой строке. Повторная обработка заново скачивает звук.

Зависимость `yt-dlp[default]` включает соответствующие JavaScript-скрипты решения проверок. Требуется поддерживаемый Node.js или Deno; см. [официальное руководство yt-dlp](https://github.com/yt-dlp/yt-dlp/wiki/EJS). Отдельный FFmpeg не нужен: декодирование выполняет PyAV. Модели и компоненты загрузчика не устанавливаются автоматически во время работы.

Обновление окружения после получения изменений:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
```

Изменения YouTube могут требовать отдельного обновления загрузчика:

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade "yt-dlp[default]"
```

## Форматы, папки и результаты

Аудио: `.ogg` (включая Telegram Ogg/Opus), `.mp3`, `.m4a`, `.wav`, `.webm`, `.amr` (AMR-NB / AMR-WB).

Видео: `.mp4`, `.m4v`, `.mkv`, `.mov`, `.avi`, `.wmv`, `.asf`, `.flv`, `.webm`, `.mpg`, `.mpeg`, `.ts`, `.mts`, `.m2ts`, `.vob`, `.ogv`, `.3gp`, `.3g2`. Используются обычные действия добавления файлов. PyAV напрямую декодирует первую звуковую дорожку; отдельное извлечение звука и установка FFmpeg не нужны. Изображения и субтитры не обрабатываются. Совместимость зависит от читаемой незашифрованной аудиодорожки и возможностей декодера. Видео без звука или с нечитаемой дорожкой получает ошибку; очередь продолжается.

Исходные файлы могут находиться в любой локальной папке. Приложение не копирует, не перемещает, не переименовывает и не удаляет их. Для видео доступны те же режимы сохранения, защита от перезаписи, TXT/Markdown, просмотр и копирование, что и для аудио.

- `inbox\` — необязательная папка входящих записей; сканируется без подпапок.
- `models\` — две локальные модели распознавания.
- `transcripts\` — результаты по умолчанию.
- `config\settings.json` — локальные настройки интерфейса, не включаемые в Git.

Структура результата в папке проекта использует дату обработки:

```text
transcripts\YYYY\YYYY-MM-DD\source-name\
  transcript.txt
  transcript.md
```

При сохранении рядом с исходником создаётся `source-name_transcript\`. Существующие папки не перезаписываются; добавляются суффиксы `_2`, `_3` и далее. TXT содержит только текст модели. Markdown добавляет источник, время обработки, длительность, определённый язык, необязательное имя говорящего и фактическую модель.

## Конфиденциальность

PyAV декодирует локальный звук; модель Whisper из папки проекта выполняет распознавание на CPU. Обработка локальных файлов не выполняет намеренных сетевых запросов. Скачивание с YouTube обращается к YouTube и серверам доставки медиа; распознавание остаётся локальным, расшифровки не загружаются в сеть. Приложение не переписывает смысл и не создаёт сводки, не дублирует исходный звук постоянно. Ранее явно запрошенная функция YouTube расширяет исходную границу офлайн-ввода из `BRIEF.md`; сам `BRIEF.md` не изменён. `inbox\`, `transcripts\`, `models\`, `.venv\` и `config\settings.json` — приватные данные окружения, защищённые правилами игнорирования Git.

## Поддержка переводов

Используются стандартные `QTranslator` и Qt Linguist. В `src/audio_transcript/translations/` находятся редактируемые `.ts` и скомпилированные `.qm`; оба вида включаются в Python-пакет. Сетевой сервис перевода не нужен. Английский каталог также задаёт формы множественного числа. Для стандартных диалогов Qt загружаются встроенные переводы Qt; системные диалоги Windows следуют языку Windows.

Новый текст интерфейса в `MainWindow` оформляйте через `self.tr("English source text")`. Используйте целые шаблоны с именованными подстановками; для количества — `self.tr("%n item(s)", None, count)`. Вызовы `_status("English source text", ...)` также извлекаются. Внутренние ключи настроек, профилей и статусов и выходные файлы не должны зависеть от переведённых подписей.

```powershell
# Обновить каталоги, сохранив существующие переводы:
.\.venv\Scripts\python.exe scripts\update_translations.py --update
# Отредактировать все четыре .ts в Qt Linguist или XML-редакторе и скомпилировать:
.\.venv\Scripts\python.exe scripts\update_translations.py
.\.venv\Scripts\python.exe -m pytest
```

Добавляйте `.ts` и `.qm` в коммит вместе. Тесты проверяют полноту, подстановки, множественное число, соответствие скомпилированных каталогов и переключение языка. При изменении рабочего процесса обновляйте все четыре README.

## Устранение неполадок

- **Модель не установлена:** запустите `bootstrap_models.bat` с интернетом. В обеих папках моделей должны быть `config.json`, `model.bin`, `tokenizer.json`.
- **Не удаётся декодировать звук:** проверьте целостность файла и поддерживаемое расширение. Ошибка одной записи не останавливает следующие.
- **Медленная обработка на CPU:** выберите профиль «Скорость». Большие модели Whisper требуют много вычислений и памяти, особенно для длинных записей.
- **`run.bat` сообщает об отсутствии окружения:** создайте `.venv` и установите проект командами выше.
- **Видео без звука:** нужна аудиодорожка; из нескольких используется первая.
- **Папка или входящие пусты:** сканируются только поддерживаемые файлы непосредственно в выбранной папке.
- **Суффикс `_2` или выше:** результат с таким именем уже существует; перезапись запрещена.
- **Проверка на бота YouTube:** доступность видео в браузере не гарантирует автоматическое скачивание. После одного повтора через 10 секунд попробуйте позже. Вход в аккаунт или обновление загрузчика не гарантирует успех; приложение не обращается к сессиям, cookies и аккаунтам браузера.
- **Другие ошибки YouTube:** используйте категорию и технические сведения для различения проблем сети, доступа, форматов и компонентов. При изменениях сервиса проверьте новую версию `yt-dlp[default]`.
- **Нет JavaScript runtime:** добавьте Node.js 22+ или Deno 2.3+ в PATH и перезапустите приложение. Локальным файлам этот компонент не нужен.
